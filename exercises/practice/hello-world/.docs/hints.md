# Hints

## General

- `hello` takes no arguments (`hello()`) and must return the exact greeting string specified in the instructions—including exact capitalization, comma spacing, and trailing punctuation (`!`).
- **Diagnostic check:** Call `hello()` with no arguments and inspect the returned string character-by-character against `"Hello, World!"`. Returning `"Hello, World"` (missing `!`) or `"Hello, world!"` (lowercase `w`) will fail the `Say Hi!` test assertion.
