# Scrabble Score Maintenance: Metadata Configuration and Path Resolution

## Overview

This maintenance document maps and verifies the metadata configuration in `exercises/practice/scrabble-score/.meta/config.json`.
It explains how the test runner locates the starter solution, test suite, and reference implementation, distinguishes maintained files from generated artifacts, and provides reproducible path validation.

| File Path | Role | Category | Maintenance Status |

## Runner Resolution Workflow

When testing the exercise, the test runner (`scripts/test.mjs` and `scripts/helpers.mjs`) resolves files as follows:
1. **Reads Metadata**: Parses `exercises/practice/scrabble-score/.meta/config.json`.
2. **Path Validation**: Verifies that `files.solution`, `files.test`, and `files.example` paths resolve strictly within `exercises/practice/scrabble-score` without escaping parent traversal (`..`).
3. **Transient Staging**: Copies the exercise directory to `tmp_exercises/practice/scrabble-score`.
4. **Reference Substitution**: Copies `proof.ci.js` into the solution destination (`scrabble-score.js`) within the temporary copy only.
5. **Test Invocation**: Executes Jest against `scrabble-score.spec.js`.
6. **Cleanup**: Removes `tmp_exercises/` preserving the immutability of the git working tree.
